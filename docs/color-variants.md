# Цветовые варианты в магазине «5 океанов»

## Как заполнить карточку в Pages CMS

**Один дизайн / одна цитата = один товар** с постоянным `slug` и `product_id`.
Название карточки не обязано включать цвет.

1. Заполните название, описание, цену и категорию «Футболки и лонгсливы».
2. В поле **Размеры** перечислите общие размеры (например, S, M, L, XL). Это не остатки.
3. Откройте **Цвета и фотографии (варианты товара)** → «Добавить».
4. На каждый цвет заведите отдельную запись:
   - **Код цвета:** `black`, `red` и т. п.; только маленькие латинские буквы, цифры и дефис. Не меняйте код после продажи.
   - **Название цвета:** «Чёрный», «Красный» — используется в подсказках и заказах, но рядом с кружком на карточке **не выводится**.
   - **Цвет кружка:** код HEX, например `#191919` и `#C62828`.
   - **Цвет доступен для заказа:** включить, когда этот цвет предлагается к продаже, выключить, когда нет. *Это не количество и не резерв.*
   - **Фотографии этого цвета:** загрузите до шести снимков. Галерея будет переключаться при выборе кружка.
   - **Размеры этого цвета:** необязательное переопределение общего списка размеров. Если оставить пустым, используются общие размеры товара.
5. При необходимости добавьте ещё цвета в **этой же карточке**. В каталоге товар останется один.

Пример структуры для понимания (пока не добавлять как реальный товар без подтверждения):

```json
{
  "title": "Футболка «Цитата» — Фёдор Конюхов",
  "slug": "futbolka-citata",
  "sizes": ["M", "L"],
  "variants": [
    {
      "code": "black",
      "label": "Чёрный",
      "hex": "#191919",
      "available": true,
      "photos": ["/media/black-shirt.jpg"]
    },
    {
      "code": "red",
      "label": "Красный",
      "hex": "#C62828",
      "available": false,
      "photos": ["/media/red-shirt.jpg"],
      "sizes": ["L"]
    }
  ]
}
```

## Что произойдёт в магазине

- Покупатель видит цветные кружки без названий. Названия доступны для экранного диктора и по подсказке мыши.
- Выбор цвета показывает его фотографии, размеры и доступность.
- Выключенный в CMS цвет показывается зачёркнутым кружком и не добавляется в корзину.
- Текст заказа и корзины содержат название выбранного цвета и размер.
- Существующие карточки **без** поля `variants` работают в прежнем режиме.

## Связь с D1 и остатками

Таблицы D1 не изменяются: сохраняем существующие заказы, их номера и резервы. Для новых цветовых вариантов в поле технического складского размера используется **однозначный ключ** `v:<code>|<size>` (например `v:black|L`, `v:red|L`). В кабинете разработчиков он показывается как «Чёрный / L» и «Красный / L», а в базе остаётся техническим.

После добавления цветов синхронизация с Pages CMS создаст для каждой комбинации цвета и размера отдельную складскую позицию с **нулевым** количеством. Реальные количества вводятся позже вручную; текущие остатки никогда не переносятся и не меняются автоматически.

Важно: отметка «Цвет доступен для заказа» означает разрешение предлагать цвет, **но не подменяет проверку наличия в D1**. Пока количество равно нулю, приобрести товар нельзя. Удаление цвета из CMS не удаляет исторические заказы; старые складские позиции автоматически не удаляются.
